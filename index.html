🎮 Cara Join

Buka Minecraft

2

Tambah Server

Klik Add Server, lalu isi nama server dengan Xyzoocraft.

3

Masukkan IP

4

Join & Enjoy

📜 Rules Server

Biar mainnya tetap nyaman, semua player wajib mengikuti aturan dasar server.

✅ Yang Boleh

  • Bangun base dan kota bersama player lain.
  • Trading item secara jujur.
  • Ikut event komunitas.
  • Membantu player baru.

❌ Yang Dilarang

  • Cheat, x-ray, bug abuse, atau exploit.
  • Griefing dan mencuri item player lain.
  • Spam chat, toxic, atau menghina player.
  • Mengganggu kenyamanan komunitas.

❓ FAQ

Pertanyaan yang sering ditanyakan sebelum masuk ke server.

Server ini Java atau Bedrock?

Default script status di bawah disiapkan untuk Java. Kalau server kamu Bedrock, ubah bagian type: "java" menjadi type: "bedrock" di JavaScript.

Apakah server aman untuk pemula?

Ya, server dibuat ramah untuk pemula. Player tetap wajib mengikuti rules agar komunitas nyaman.

Apakah boleh membuat toko sendiri?

Boleh. Xyzoocraft mendukung sistem ekonomi dan toko pemain.

Bagaimana kalau ada player toxic atau griefing?

Laporkan ke admin/moderator melalui komunitas agar bisa ditindak sesuai rules.
